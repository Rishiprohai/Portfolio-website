PORTFOLIO SETUP

1. Put index.html, style.css and script.js in the same folder.
2. Open index.html in VS Code with Live Server, or double-click it in your browser.
3. Replace these placeholders in index.html:
   - YOUR NAME / Your Name
   - [College / Branch] area in Education
   - your.email@example.com
   - github.com/yourusername
   - linkedin.com/in/yourusername/
4. To add real project photos, replace the CSS-generated project visuals with <img> tags or add background images in style.css.
5. When ready to publish, upload the folder to GitHub Pages, Netlify, Vercel, or your own hosting.
